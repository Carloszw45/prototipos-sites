# Florê Buquês

Loja demonstrativa inspirada na referência visual lilás fornecida. Projeto estático, sem dependências de execução.

## Apresentação pública

https://carloszw45.github.io/prototipos-sites/flore-buques/

## Experiência

- Dois produtos por linha no celular e quatro no computador.
- Categorias, seleções especiais, busca, filtros e ordenação.
- Detalhes dos buquês, favoritos e sacola persistidos no navegador.
- Quantidades, subtotais e resumo de pedido com opção de copiar.
- Checkout demonstrativo: não envia pedidos, coleta dados em servidor nem recebe pagamentos.
- Fontes e fotografias locais, sem dependência de imagens externas durante a navegação.
- Diálogos nativos, navegação por teclado e respeito a movimento reduzido.

Nome, produtos e preços são ilustrativos. Nenhuma avaliação, disponibilidade de estoque ou condição de entrega real é anunciada. A indexação é desativada enquanto o site usa marca e catálogo provisórios.

## Arquivos

`index.html`, `style.css`, `store.js`, `app.js` e `assets/`. Para publicar, mantenha a pasta completa. O GitHub Pages do repositório serve essa pasta diretamente; não há compilação.
